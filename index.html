Personal desktop integration

Rclone Personal Drive

This page describes a personal, owner-operated configuration of rclone for accessing the owner's Google Drive from a Windows computer.

The purpose is to mount the owner's Google Drive as a local virtual drive, so they can browse, open, upload, and manage their own files using the Google Drive API.

How access works

Google OAuth is used to authorize the locally installed rclone application. The requested Google Drive permission can allow the owner to view, create, modify, move, and delete files through rclone. Authorization is performed by the owner, and the resulting credentials are stored locally in the rclone configuration, not on this website.

This is an informational site for a personal desktop setup. There is no public registration, hosted file-processing service, or online account dashboard.

Data and privacy

File operations take place between the owner's computer and Google Drive. Local caching may be used by rclone. Please read the Privacy Policy for information about Google user data and authentication.
