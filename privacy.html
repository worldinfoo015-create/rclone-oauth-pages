Privacy Policy

Effective date: October 21, 2026

Rclone Personal Drive is a personal configuration of the open-source rclone desktop software. It is operated by its owner on their own Windows computer to access their own Google Drive account. This page describes that personal configuration, not every possible use of rclone.

Google account access

The owner authorizes rclone through Google OAuth. The Google Drive access scope may permit viewing file lists and contents; creating and uploading files; and editing, moving, or deleting files and folders when instructed by the owner.

Use of Google user data

Google Drive file data is accessed only to perform file-management actions selected by the owner. Transfers occur between the owner's computer and Google Drive through Google's API. The configuration is not intended to sell Google user data, show targeted ads, or use Google user data to train machine-learning models.

Storage and security

OAuth tokens are saved locally in the owner's rclone configuration. Files and metadata may also be stored or cached locally, according to rclone's configuration. This informational GitHub Pages website does not receive or store OAuth tokens, passwords, or Drive files. The owner controls access to their Windows computer and can revoke rclone's Google account access at any time from Google Account settings.

Sharing and third parties

This personal setup has no separate hosted backend receiving Google Drive files. Google processes API requests needed for the connection. The public informational pages are hosted on GitHub Pages, which may process website visit information under its own policies. Data is not sold by this personal integration.

Data retention and deletion

Local tokens can be removed by deleting the local rclone configuration entry, and cached data can be cleared using rclone's supported procedures after confirming all writes have completed. Revoking access in Google Account settings prevents further authorized access. Deleting a file through rclone may also delete it from Google Drive.

Contact

For questions about this personal setup, refer to the project repository.
